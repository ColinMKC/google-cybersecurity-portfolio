# Controls and Compliance Checklist

## Scenario
Internal security audit for **Botium Toys**, a small toy company. Using the audit's scope, goals, and risk assessment, I evaluated which controls and compliance best practices were in place.

## What I did
- Assessed 14 administrative, technical, and physical controls (least privilege, firewall, IDS, encryption, backups, CCTV, etc.)
- Checked compliance against **PCI DSS**, **GDPR**, and **SOC type 1 / type 2** best practices
- Wrote recommendations for the IT manager to communicate to stakeholders

## Key recommendations
- Enforce least privilege and separation of duties; limit access to credit card data and PII/SPII on a need-to-know basis
- Encrypt customers' credit card information
- Install an intrusion detection system (IDS)
- Create disaster recovery plans and back up critical data
- Strengthen password requirements and adopt a centralized password management system
- Upgrade legacy systems, or put them on a strict monitoring and maintenance schedule
